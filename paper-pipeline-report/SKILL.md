# 论文数据管线讲透

交付一份可直接阅读的中文报告。读者应能沿着一条数据说清：它从哪里来，经过什么处理、为什么，失败时如何处理，最后怎样组成模型输入和监督。多篇报告还须解释管线之间可比较的差异。材料、写作、核验和修订由助手完成，不把技能组合变成用户的操作清单。

## 默认交付约定

- 默认读者有基本技术常识，尚未读过论文。用户给参考文档时，提取解释深度、证据口径、图文组织方式，不照搬其事实或瑕疵。
- 输入和目标明确就直接完成全文；只在身份、访问或影响结论的范围缺失时才问。不重新询问已有的文风、技能选择或逐节审批。
- 默认交付一份 Markdown 报告及引用图片，服从指定格式、目录。解析文本、提纲、评测分数或几篇独立摘要不能代替成稿。长度取决于信息量，不能为简短省略重要分支。
- 本技能自包含，不必安装整套辅助技能。需要借助当前环境已有技能时，按 [references/skill-routing.md](references/skill-routing.md) 选择相关部分。

## 从原文重建管线

1. 固定标题、版本、来源。复用匹配版本的本地原文与解析结果，再补取缺失正文、附录、图表。不能用搜索摘要代替全文；不可访问的部分限定范围，不从别篇论文补齐。
2. 对 PDF，优先使用可用的 Doc2X MCP 取得结构化 Markdown 与图片，复用已有结果。Doc2X 任务串行执行，按 UID 查询；超时先查原任务，避免重复提交。不可用时用原文 HTML、PDF 页面渲染等继续。pypdf 可辅助检索，但不承担图表和公式的最终核验。
3. 关键数字、公式符号、合并表头、图中分支、正文与附录差异，回看原始页面。任何解析器都可能出错；解析块页号不一定等于物理页码。记录版本、章节、PDF 页码和图表号用于引用。
4. 在工作记录中追踪重要步骤：输入对象 → 操作及条件 → 输出对象 → 失败处理 → 训练用途，附证据位置和待核问题。不要把并行来源画成串行流程，也不要假定所有来源经过同一清洗器。

## 正文的解释深度

每篇先给一句话流程，再沿数据变化展开。表格可承载“方法与参数 / 原因及输出 / 复现缺口”；关键机制仍需连续文字解释。多篇时开头给可比较总览，结尾讲共同点、差异和适用条件。结构随材料调整，不机械套满模板。

对决定理解的步骤，讲清以下关系，而非只列算法名称：

- **对象与粒度：** 帧、片段、episode、数据集、维度还是损失项？分清剔除、修正、重标注、重采样、损失屏蔽。
- **机制与原因：** 什么错误会污染什么监督，这一步如何解决，不做可能怎样？技术解释不能伪装成作者做过消融的因果结论。术语首次出现时解释在这里实际做什么；小例子标为示意，不虚构作者实验。
- **规则与例外：** 保留影响方法含义的条件、阈值、坐标系、时间关系、例外和关键公式，解释公式各量对应什么数据。
- **训练落点：** 最终一个样本有哪些输入和标签，缺失维度、无效时间步怎样处理，混合或采样怎样影响训练。查过相关内容仍未披露的，才标为未知。
- **就地防误读：** 在相关段落说清统计分母、规模口径、真实与合成、标注上下文与部署输入、过滤与修复的区别，不把澄清全堆到末尾，不凭空编造误解。
- **证据边界：** 分清作者明确描述、本文机制解释、当前版本未披露。正文没给时先查相关附录；未披露不等于所有外部代码都没有。不能把甲论文的参数移植为乙论文的实现。

涉及性能时交代比较条件、数据与模型是否同时改变、指标衡量什么、消融隔离了什么。整体系统变好不证明每个清洗步骤都有效。聚焦数据管线，不扩展成无关的全面审稿。

## 图像属于成稿

选择解释关键管线和分支所需的论文原图，读图后放在相关正文旁，注明论文版本、图号、PDF 页码和应关注的关系。原图不能表达的必要关系可补“本文绘制”示意图，不伪装成作者原图。

必须使用实际图片嵌入 `![有意义的说明](路径)`，不能仅写图号、文件名或代码块。报告与图片一起交付；可移植文件用相对路径，需要绝对路径的聊天/预览环境另提供对应版本。逐一确认图片存在，打开关键图检查清晰度、裁剪和图注。目标阅读器不支持 Mermaid 时给可见的图像替代。拿不到图时明确缺口，不以不相干配图掩盖，不声称已验证未检查的渲染能力。

## 自动检查、修订、交付

先查事实：数字和分母、坐标和符号、条件 AND/OR、处理粒度、附录例外、引用定位与图片对应。未核实的重要问题限定表述，不能凭解析成功宣称全文准确。

再查读者理解。本技能请求在可用且允许委派时，用一个未参与写作的新上下文读者，只给成稿，不给过程或预设答案。让它还原输入到训练样本、解释一个关键操作的原因、比较两条管线（单篇则解释两处分支），指出需要自行补背景或容易误读的段落。按实际问题修订，事实改动回查原文，重要修改请读者复查。不以固定分数或机械复述断定“讲透”。无法独立委派时做同样自检，准确说明独立检查未执行，不要求用户自己扮演审稿人。

交付前确认覆盖全部请求论文、关键引用可定位、图片有效、已知问题已修正或透明限定。最终回复以成稿链接和必要限制为主。工具日志、工作记录和检查材料作为附属材料，不占据读者正文。写作授权不自动包含公开发布报告。
