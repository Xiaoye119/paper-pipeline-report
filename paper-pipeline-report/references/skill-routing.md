# 可选辅助技能：助手内部选择

需要下列具体帮助时才读取环境中实际存在的 SKILL.md。技能名不是可执行函数；“调用”指读取指令并完成相关工作，或将明确子任务交给代理。找不到时按主技能继续，不让用户补装整套工具，不声称调用过。

| 需要 | 可选技能 | 本任务采用的部分 |
|---|---|---|
| PDF 结构化解析、提图和页面核对 | `doc2x-cli`、`pdf` / `pdf:pdf` | 已连接 MCP 优先于另装 CLI；串行、任务复用和原页核验。真的使用 CLI 时再执行其版本前置检查。 |
| 解释术语化、单篇贡献不清 | `ljg-paper` | 具体对象与动作、研究贡献、证据如何支持判断。请求改写相关解释，不额外引入笔记目录、Denote、Emacs 等无关交付体系。 |
| 多篇结构松散、读者自行拼接 | `doc-coauthoring` | 结构精炼和新上下文读者测试。本任务采用一次成稿并自动检查，不启用逐节征询、选题菜单或反复审批。 |
| 实验结论或归因边界不清 | `scientific-critical-thinking` | 比较条件、混杂因素、实验单位和适用范围，不默认套医学评级或给每篇总分。 |

这些不是每次必跑的固定顺序。需要某辅助技能的完整独立产物时再明确该子任务；其格式约定与用户要求不同时保持用户要求。遵守实际使用资源的许可与署名，不复制打包辅助技能全文。
